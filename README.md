# clip-permission-templates

Plain-language templates for a streamer and a clip editor who want to work together without guessing who may do what with the footage. Fill in the brackets, both sides sign (a confirming email counts), keep a copy.

**These are starting templates, not legal advice.** Laws differ by place; have a lawyer review before you rely on them for paid work.

## What's inside

| File | Use it to |
|---|---|
| `clip-permission-agreement.md` | Agree what footage the editor may use, who owns the finished clips, payment, deletion and ending the deal. |
| `do-not-clip-list.md` | Tell the editor what must never be clipped (guests without consent, licensed music, private info, sponsor-restricted parts). |
| `clip-log.csv` | Track every clip: source VOD, timestamps, status, approval date, where it was posted. Open in any spreadsheet. |
| `revoke-permission-notice.md` | A short note a creator can send to end permission at any time. |
| `deletion-confirmation.md` | A short note an editor sends once source files and working files are deleted. |

## How to use

1. Streamer and editor agree on the package and fill in `clip-permission-agreement.md`.
2. Streamer fills `do-not-clip-list.md` before the first clip.
3. Editor records every clip in `clip-log.csv` and delivers only to the streamer.
4. When the work ends, use the deletion note.

## Principles built in

- The editor only works on footage the creator has given permission for, and only for the creator.
- Nothing is posted, sold or monetized by the editor unless the creator opts in separately and in writing.
- Permission is revocable at any time.
- The creator keeps all revenue from the clips.
